
## 🔧 Persyaratan

- Python 3.8 atau lebih baru
- Windows (untuk `run.bat`), atau OS lain dengan menjalankan `main.py` langsung

## 🚀 Cara Pakai

1. Clone repository ini:
```bash
   git clone https://github.com/Jetlagggg/tools-organizer-folder.git
   cd tools-organizer-folder
```
2. Jalankan program:
   - Windows: klik dua kali `run.bat`
   - Atau lewat terminal:
```bash
     python main.py
```
3. Ikuti instruksi yang muncul di layar.

## ⚠️ Catatan

Disarankan mencoba di folder percobaan dulu sebelum dipakai di folder penting, karena program ini memindahkan file.
